# 安全与合规检查清单

## 账户与权限

- [ ] 密码安全存储，Token 可刷新、撤销和过期
- [ ] 用户端、审核端、客服端和管理员权限隔离
- [ ] 后台高风险操作二次确认并记录审计日志
- [ ] 超过 200 元现金退款由财务二次审核
- [ ] 超过 1000 积分人工调整由超级管理员二次审核
- [ ] 超过 1000 人批量发券由超级管理员确认
- [ ] 二次审核人与申请人不是同一后台账号
- [ ] 完整手机号、地址查看和用户数据导出使用独立权限
- [ ] 登录、验证码、上传和敏感接口有限流及风控

## 数据与隐私

- [ ] 只收集业务所需的最少信息
- [ ] 隐私政策列出第三方 SDK、权限用途和数据共享方
- [x] 用户可以申请导出、更正和注销账号（正式环境仍需法务与真机验收）
- [ ] 用户可以申请删除、撤回可选授权并查看适用协议版本
- [ ] 数据类别绑定保留规则，到期删除/匿名化任务可审计、可重试
- [ ] 普通资料注销后30天、登录日志180天、任务附件180天及交易/资产期限按确认矩阵验证
- [ ] 删除覆盖对象存储、搜索和缓存；备份恢复后重放删除清单
- [ ] MVP不面向14周岁以下儿童独立提供服务，默认无个人信息跨境处理
- [ ] 日志、备份和测试数据完成敏感信息脱敏
- [ ] 密钥使用环境变量或密钥服务，不进入 Git

## 交易安全

- [ ] 支付回调验签、金额核对和幂等
- [ ] 小程序、微信内 H5 与微信外 H5 支付分别校验应用身份、用户身份和支付场景
- [ ] 积分、库存、订单和退款变更使用事务及流水
- [ ] 混合支付的现金、积分分别记账、退款和对账
- [ ] 部分退款累计现金和积分不超过原订单实际支付
- [ ] 积分奖励事件具有唯一事件键、次数上限和防刷策略
- [ ] 发帖、评论删除或违规下架后的积分撤销规则可审计
- [ ] 后台人工补偿有权限、原因、审批和审计
- [ ] 每日支付、退款、积分和库存对账
- [ ] 余额支付、提现、退款和人工调整使用不可删除流水
- [ ] 提现申请先冻结余额，成功扣除，失败或拒绝解冻
- [ ] 后台余额清零通过反向流水，不直接覆盖余额
- [ ] 余额增减、清零和提现审核记录操作人及审批人

## 输入与文件

- [ ] 防止 SQL 注入、XSS、CSRF、越权和重放
- [ ] 上传限制类型、大小、数量和访问权限
- [ ] 私有文件使用授权地址或临时签名
- [ ] 用户内容具备审核、举报和下架机制

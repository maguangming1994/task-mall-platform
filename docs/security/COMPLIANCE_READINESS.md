# 合规文本、主体资质与第三方账号准备清单

## 1. 状态说明

第二十四组已确认的是准备范围、责任边界和“未取得资质就关闭功能”的原则，并不代表真实证照、平台账号、合同或法务签字已经取得。

任何正式资料必须由项目真实运营主体提供并由对应负责人验真；开发环境只使用测试凭证，不能用模拟资质发布生产功能。

## 2. 运营主体资料

- [ ] 运营主体全称、统一社会信用代码和营业执照
- [ ] 注册地址、实际经营地址和有效联系方式
- [ ] 客服电话、客服邮箱、服务时间和投诉升级联系人
- [ ] 个人信息保护负责人或联系渠道
- [ ] 商标、品牌名称、Logo 和授权关系
- [ ] 商品类目涉及的经营许可、质检、授权或备案资料

## 3. 正式规则文本

- [ ] 用户服务协议
- [ ] 隐私政策、儿童/未成年人说明和个人信息处理清单
- [ ] 第三方 SDK、共享对象与系统权限用途清单
- [ ] 任务参与、审核、奖励、投诉和申诉规则
- [ ] 积分、优惠券、钱包余额和提现规则
- [ ] 商城交易、配送、退款、退货、换货和运费规则
- [ ] 社区内容、举报、处罚和申诉规范
- [ ] 账号注销和数据权利说明
- [ ] 未来外部发布者协议、资金、结算和退出规则（首发不启用）

所有文本保存版本号、生效时间、适用端、用户同意记录和历史版本。重大变更必须重新提示，并按届时适用要求决定是否重新取得同意。

## 4. 微信与支付资源

- [ ] 微信小程序 AppID、主体认证、服务类目和服务器域名
- [ ] 公众号 AppID、网页授权域名和 JS 接口安全域名
- [ ] 微信开放平台及小程序/公众号关联关系（如采用 UnionID）
- [ ] 微信支付商户号、AppID 绑定、APIv3 密钥、平台证书和退款权限
- [ ] 小程序支付、JSAPI 支付和 H5 MWEB 支付的实际开通状态
- [ ] 支付/退款通知域名、验签证书轮换和商户平台操作人
- [ ] 提现渠道、收款身份、手续费、对账单和异常处理权限

未开通的支付场景必须在 `/client-capabilities` 中返回关闭，不生成不可支付订单。

## 5. 域名、基础设施和第三方服务

- [ ] 正式域名、ICP备案、DNS、HTTPS 证书和续期负责人
- [ ] 云账号、服务器区域、数据库、Redis、对象存储、CDN 和备份资源
- [ ] 短信签名/模板、对象存储桶、物流查询、地图、客服和监控账号
- [ ] 每项第三方的合同主体、数据范围、保存期限、子处理方和退出/删除机制
- [ ] 密钥管理、最小权限子账号、账单告警和人员离职交接

## 6. 财务、税务与知识产权

- [ ] 商品销售、余额奖励、提现手续费、退款和运费补偿的会计口径
- [ ] 发票开具主体、类型、申请入口、红冲和售后处理
- [ ] 支付、退款、提现、余额、积分和预算对账负责人
- [ ] 字体、图标、插画、商品图片、文案和用户内容的授权或使用规则
- [ ] 用户侵权投诉、下架、证据保全和反通知流程

## 7. 上线阻断规则

- 真实运营主体和客服/隐私联系方式未填写：不得发布正式协议或提交平台审核。
- 对应微信、支付、短信、域名或经营资质未取得：对应功能保持关闭。
- 第三方处理范围未完成清单和安全评估：不得接入生产数据。
- 法务、财务、安全或业务负责人未完成职责范围签字：不得进入生产灰度。
- 外部用户/机构发布继续保持 `closed`，直到其专项上线硬门槛全部满足。

# 全链路 UAT 验收矩阵

## 自动化证据

执行 `scripts/uat.ps1 -Release <版本号>` 会先运行三端类型检查、代码检查、生产构建、Laravel 全量测试和格式门禁；全部通过后才创建不可修改的 UAT 报告。报告包含版本、环境、场景结果、SHA-256 报告摘要和完成时间，后台可通过 `/api/v1/admin/operations/uat-runs` 查询。

本地 UAT 覆盖运行依赖、业务一致性、核心路由契约、定时命令覆盖和完整自动化回归。外部渠道与真机未执行时标记为 `blocked`，不会伪装成通过；本地结果状态为 `passed_local`。

## 真实渠道矩阵

| 场景 | 小程序 | 微信内 H5 | 外部浏览器 H5 | 通过证据 |
|---|---|---|---|---|
| 登录与身份归一 | code2Session | 公众号 OAuth | 手机验证码 | 同一 UnionID 归一且冲突不静默合并 |
| 支付 | JSAPI | JSAPI | MWEB | 金额一致、签名通过、重复通知只结算一次 |
| 退款/部分退款 | 查询到账 | 查询到账 | 查询到账 | 多次累计不超实付，积分按退款到账重算有效期 |
| 提现 | 微信转账 | 微信转账 | 微信转账 | 千分之六手续费快照、失败解冻、成功不可重放 |
| 消息 | 订阅/模板消息 | 模板消息 | 站内信/短信 | 必要消息绕过免打扰，营销只触达订阅用户 |
| 上传与内容安全 | 私有直传 | 私有直传 | 私有直传 | 未扫描文件不可访问，恶意内容失败关闭 |
| 物流与售后 | 实物/无需物流 | 实物/无需物流 | 实物/无需物流 | 退货期限、凭证、数量和退款上限一致 |

## 需要提供的上线输入

- 小程序和公众号 AppID/AppSecret、授权域名、业务域名及测试微信账号。
- 微信支付商户号、商户证书序列号、私钥、32 字节 APIv3 密钥、平台证书与回调域名。
- 短信、病毒扫描、内容安全、物流查询供应商凭据；正式微信消息模板 ID。
- 测试商户/用户/管理员账号、至少一台 iOS 与一台 Android 真机、业务验收和财务验收负责人。
- 正式协议文本、运营主体、客服及隐私联系人。

真实输入齐备并完成矩阵后，执行 `scripts/uat.ps1 -Release <版本号> -ExternalChannels -RealDevice`。只有生产就绪门禁同时通过，外部渠道结果才会记录为通过。

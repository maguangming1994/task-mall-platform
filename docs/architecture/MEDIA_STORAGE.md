# 全站图片与对象存储

## 能力范围

后台的商品、任务、任务步骤、首页与外观、社区装修、协议及其他富文本图片共用统一素材入口。每次添加图片可以选择：

| 方式 | 行为 | 适用场景 |
| --- | --- | --- |
| 本地上传 | 校验真实图片后写入当前启用的公共素材存储 | 管理员电脑中的长期素材 |
| 链接转存 | 服务端安全下载 HTTPS 图片，校验后写入当前公共素材存储 | 已有网络图片，且不希望依赖原站 |
| 直接外链 | 只保存 HTTPS 地址，不下载、不创建素材记录 | 临时且可信的第三方图片 |

公共素材支持 JPG、PNG、WebP，单张不超过 10MB。链接转存拒绝内网、环回和保留地址，固定已校验的 DNS 解析结果，不跟随重定向，并在流式读取时执行 10MB 硬限制。

直接外链会让访客设备直接请求第三方网站，可能受源站失效、防盗链、隐私策略和微信小程序下载域名白名单影响。生产长期素材应优先上传或转存。

## 公共和私有边界

公开运营图片与用户受控文件共用“当前存储供应商”，但不共用公开空间：

- `bucket`：公共素材桶或空间，仅存放 `media/` 下的站点图片，可通过公开域名或 CDN 访问。
- `private_bucket`：私有上传桶或空间，存放 `quarantine/` 下的头像、帖子附件、任务凭证、退款/售后证明和线下充值证明。
- 两个桶必须不同。私有桶必须保持私有读写，不能绑定公开 CDN 或匿名读取策略。
- 私有桶的 CORS 只允许正式 H5 域名使用 `PUT`，并放行预签名上传返回的 `Content-Type`、`x-amz-acl` 等请求头；小程序还需登记对象存储上传域名。
- 私有文件仍使用上传票据、所有者校验和安全扫描，扫描通过前不能下载，也不开放“直接外链”绕过检查。

每个私有文件在创建上传票据时绑定当时的供应商。切换供应商后旧文件仍从原供应商读取；已有文件时禁止直接更换对应的 Endpoint、Region 或存储桶，避免旧文件断链。密钥轮换会先用候选配置完成连通性与访问边界测试，成功后才保存；扫描队列每次动态构建云盘，不会继续使用旧凭据缓存。

为兼容升级前的生产部署，本地素材供应商下的受控上传仍遵循 `UPLOAD_DISK=local|s3`；启用腾讯云或七牛云供应商后，新的受控上传改用该供应商的 `private_bucket`。

## 存储供应商

| 驱动 | 主要用途 | 必填配置 |
| --- | --- | --- |
| 本地存储 | 本地开发、临时部署 | 公开访问地址 |
| 腾讯云 COS | 生产对象存储 | S3 兼容 Endpoint、Region、公共 Bucket、私有 Bucket、公开/CDN 域名、SecretId、SecretKey |
| 七牛云 Kodo | 生产对象存储 | S3 兼容 Endpoint、Region、公共空间、私有空间、公开/CDN 域名、AccessKey、SecretKey |

示例：

- 腾讯云广州：Endpoint `https://cos.ap-guangzhou.myqcloud.com`，Region `ap-guangzhou`。Bucket 名称应包含腾讯云 APPID。
- 七牛云华南：Endpoint `https://s3.cn-south-1.qiniucs.com`，Region `cn-south-1`。不同区域必须使用对应 S3 Endpoint。
- `public_base_url` 建议填写已配置 HTTPS 的图片 CDN 域名，例如 `https://img.example.com`，不要包含对象路径、查询参数或片段。

供应商的 S3 兼容参数应以官方文档为准：[腾讯云 COS S3 兼容说明](https://intl.cloud.tencent.com/document/product/436/32537)；[七牛云 Kodo S3 域名说明](https://developer.qiniu.com/kodo/4088/s3-access-domainname)。

云密钥使用应用加密保存，API 不回传明文。配置、测试、切换和迁移要求 `settings.manage` 权限及近期身份验证，并写入操作审计。公共图片上传按实际业务权限开放给商品、任务、社区、协议和站点设置管理员。

## 配置与切换

1. 在后台“系统设置 -> 图片与对象存储”打开腾讯云 COS 或七牛云 Kodo。
2. 填写 Endpoint、Region、公共桶、私有桶、公开域名和访问密钥。
3. 保存并执行连通性测试。测试会在真实业务前缀 `media/health-check/` 与 `quarantine/health-check/` 下校验两个桶的写入、读取和删除，同时确认公共域名可匿名读取、私有桶不可匿名读取。
4. 选择“切换使用”。之后公共素材写入公共桶，新的用户受控上传写入私有桶。
5. 如需搬迁已有公共素材，选择“迁移并切换”。私有文件不会在此任务中搬迁，并继续从原供应商读取。

素材 API 返回稳定地址 `/api/v1/media/assets/{asset_id}`。该地址短暂缓存后重定向到素材当前实际地址，所以任务、装修配置和富文本不会因后续公共素材迁移而保存过期的云地址。修改公开/CDN 域名时，系统会先测试候选域名，再在同一数据库事务中回填该供应商已有素材的实际地址。历史版本中已经保存的实际存储地址不具备这一能力；系统会强制这类迁移保留源文件，防止历史页面断图。

稳定素材地址不使用按访客 IP 聚合的应用层限流，避免校园网或企业网共享出口造成正常图片请求返回 429。生产环境应由 CDN、Nginx 或 WAF 对该公开只读入口做缓存和异常流量防护。

迁移任务逐个流式复制并校验文件大小，再更新素材记录。单个对象失败时保留原地址；后台展示失败数量和摘要。大规模迁移应在低峰期执行并监控队列、对象存储错误率与 CDN 可用性。

## 生产部署

生产 Compose 使用 `app-storage` 卷持久化 `storage/app`。Nginx 只读暴露 `/storage/` 对应的公共目录，私有目录不会映射为静态资源。使用 COS 或 Kodo 后，生产应用仍应保留该卷，用于框架缓存及切换前的历史本地文件。

首次部署本版本时，先备份现有 API 容器的 `storage/app`，再执行 `php artisan migrate --force` 并启动新 Compose 卷。如旧容器已存在本地图片，需将备份恢复到 `app-storage` 卷，确认 `/storage/media/` 可访问后再销毁旧容器。

微信小程序需要把正式 API 域名和图片 CDN 域名加入微信公众平台对应的合法域名列表。直接外链还要求第三方图片域名满足小程序规则，因此不建议用于核心页面。

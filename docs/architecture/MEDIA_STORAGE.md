# 商品图片与对象存储

## 统一素材入口

后台商品主图和轮播图支持两种导入方式：

- 从管理员电脑选择 JPG、PNG 或 WebP 文件上传，单张不超过 10MB。
- 输入可直接访问的 HTTPS 图片地址。服务端下载并校验真实图片类型后，转存到当前存储，不直接依赖第三方网址。

每张图片创建独立素材 ID。商品保存素材 ID、展示地址、图片说明和排序；第一张图片为主图。读取商品时根据素材 ID 解析最新地址，因此存储迁移不需要逐条重写商品定义。

## 存储驱动

| 驱动 | 用途 | 关键配置 |
| --- | --- | --- |
| 本地公共存储 | 本地开发、临时预览 | 公开访问地址 |
| 腾讯云 COS | 生产对象存储 | S3 兼容端点、Region、Bucket、公开/CDN 域名、SecretId、SecretKey |
| 七牛云 Kodo | 生产对象存储 | S3 兼容端点、Region、空间、公开/CDN 域名、AccessKey、SecretKey |

上传过程不主动修改对象 ACL，以兼容关闭 ACL 的存储桶。公开读取权限应在存储桶或 CDN 回源策略中统一配置。

云密钥使用应用加密保存，API 不回传明文。配置、测试、切换和迁移均要求 `settings.manage` 权限；写操作还要求管理员近期身份验证，并写入操作审计。

## 切换与迁移

1. 保存并启用目标存储配置。
2. 执行写入、存在性检查和删除测试。
3. 选择“迁移并切换”。系统在一个数据库事务内将新上传切到目标存储，并创建旧素材后台迁移任务。
4. 后台任务逐个流式复制、校验文件大小，然后更新素材地址。
5. 单个文件失败时保留原存储和原地址，不影响访问；后台显示失败数量与最多 50 条失败摘要，可修复配置后再次迁移剩余文件。
6. 可选择在校验成功后删除源文件。首次迁移建议保留源文件，确认业务稳定后再清理。

生产队列工作进程的单任务超时为 3600 秒，以支持批量素材迁移。大规模迁移应在低峰期执行，并监控队列积压、失败数、对象存储错误率和 CDN 可用性。

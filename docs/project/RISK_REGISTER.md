# 风险登记表

| 风险 | 概率 | 影响 | 缓解措施 | 状态 |
|---|---|---|---|---|
| 支付或小程序资质准备延迟 | 中 | 高 | 按合规准备清单补齐主体、类目和支付渠道；未开通场景保持关闭 | 等待外部资料 |
| 任务成果包含违规内容 | 中 | 高 | 文件隔离、内容审核、举报、冻结、申诉和下架规则已确认 | 待实现 |
| 发帖评论刷积分或产生违规内容 | 高 | 高 | 奖励上限、幂等事件、审核、举报、风控和违规追回规则已确认 | 待实现 |
| 积分被重复发放或恶意刷取 | 中 | 高 | 幂等键、风控、审核审计、设备与账号限额规则已确认 | 待实现 |
| 并发下单导致库存超卖 | 中 | 高 | 库存预占、原子更新、事务和并发测试 | 待实现 |
| 多端体验和能力不一致 | 高 | 中 | 平台适配层、能力矩阵和真机回归基线已确认 | 待实现 |
| UI 资源反复修改影响开发 | 中 | 中 | 设计领先一迭代，组件与 Token 先行；品牌资料待补 | 监控中 |
| 单人开发范围失控 | 高 | 高 | MVP v1.0 已冻结，新增需求必须提交变更申请 | 监控中 |
| 环境或版本不一致 | 中 | 中 | 锁定版本、Docker 化和一键启动说明 | 待实现 |
| 数据丢失或迁移失败 | 低 | 高 | 自动备份、恢复演练、迁移回滚和灰度发布 | 待实现 |

每周复查概率、影响、负责人和缓解动作。新增高风险项必须进入项目看板。

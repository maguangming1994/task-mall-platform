## 安全边界

- 普通用户、前端任务发布者与管理后台使用不同 Token audience，三类令牌不能互换。
- 后台 Access Token 只用于短期请求；Refresh Token 明文只返回给客户端，数据库仅保存 SHA-256 摘要。
- 管理端令牌保存在浏览器 `sessionStorage`，关闭会话后不做长期保留；正式生产可进一步升级为同站 HttpOnly Cookie。
- 账号停用、会话撤销、空闲到期和最大期限在每次后台请求中检查；权限也在服务端实时查询。
- `requires_mfa=true` 的账号当前会安全拒绝登录，待二次验证流程完成后才能开放。
- 开发验证码 `246810` 只在 `local/testing` 环境生效；其他环境使用日志驱动会直接失败。
- 项目没有默认后台账号或通用密码，首位管理员必须由有主机权限的运维人员显式创建。
- OpenID、UnionID、AppSecret、微信 Access Token 和临时 code 不进入前端响应、业务日志或审计内容。
- 公众号 OAuth 回调校验一次性 state；微信临时 code 仅由服务端向微信换取身份。
- 身份归并只移动登录身份归属并撤销原账号会话，不重写订单、资产、积分或审计流水。
- 本地种子协议醒目标注“不可用于生产”；生产环境不会自动创建任何占位法律文本。
- 发布协议需要 `legal.manage` 专用权限、明确审核确认和原因，并写入后台审计。

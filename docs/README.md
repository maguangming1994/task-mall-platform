# 项目文档

- `PROJECT_ROADMAP.md`：从立项到上线运营的统一路线图和进度基线
- `product`：需求基线、范围、指标和验收标准
- `architecture`：系统边界、模块依赖和关键技术决策
- `api`：接口约定、错误码和认证方式
- `business`：任务、积分、库存、订单与支付状态机
- `database`：数据模型、索引和迁移说明
- `quality`：测试策略、设备矩阵和质量门槛
- `security`：安全、隐私和合规检查
- `project/I1_PRODUCTION_READINESS.md`：真实微信、短信、扫描器、主体法务和生产门禁清单
- `project/PRODUCTIZATION_STATUS.md`：当前视觉、演示数据、本地 UAT 与真实联调阻塞
- `project`：风险、决策、变更和进度记录
- `releases`：发布、灰度和回滚检查
- `operations`：发布、监控、备份与故障处理

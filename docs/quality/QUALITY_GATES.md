# 质量门槛

第二十九和第三十组已确认的非功能目标及完整验收矩阵分别见 [`NON_FUNCTIONAL_REQUIREMENTS.md`](NON_FUNCTIONAL_REQUIREMENTS.md) 和 [`ACCEPTANCE_TEST_MATRIX.md`](ACCEPTANCE_TEST_MATRIX.md)。

## 测试层级

- 单元测试：状态转换、金额/积分计算、权限和幂等逻辑。
- 接口测试：参数校验、错误码、认证、分页和数据权限。
- 集成测试：数据库、Redis、队列、对象存储和支付适配器。
- E2E 测试：任务积分闭环与商城订单闭环。
- 并发测试：任务名额、提交撤回与审核锁定、奖励幂等、库存预占、积分发放和支付回调。
- 任务名额并发断言：当前占位加成功奖励始终不超过最大成功奖励次数，领取失败不残留用户任务或奖励预留。
- 真机测试：微信小程序、H5、Android 和 iOS。

## 发布阻断条件

- [ ] 阻断和严重缺陷为零
- [ ] 任务、发奖、下单、支付、退款和提现主链路没有 P0/P1 缺陷
- [ ] 核心 E2E 全部通过
- [ ] 数据库迁移与回滚验证通过
- [ ] 权限越权和支付幂等测试通过
- [ ] 无库存负数、重复积分或重复退款
- [ ] 资产流水与账户汇总对账一致率 100%，无重复发奖和账务差异
- [ ] 预发布环境支付技术成功率不低于 98%，失败原因可追踪
- [ ] 关键接口错误率和延迟达到基线
- [ ] 用户端加载、空、错误和无权限状态完整
- [ ] 多端设计走查和真机检查通过
- [ ] 日志中不包含密码、Token、密钥和敏感隐私数据
- [ ] 隐私请求、注销30天处理、保留到期、跨存储删除和备份重放测试通过
- [ ] 正式协议与第三方清单已填入真实主体信息并完成法务复核
- [ ] 未取得资质或生产账号的支付、短信、外部发布等能力保持关闭
- [ ] 禁止内容、外链白名单、恶意文件、重复材料和多账号风险测试通过
- [ ] 自动风控不会直接产生未经人工复核的永久处罚
- [ ] 首发外部任务发布能力固定为 `closed`，普通用户 Token 无法探测或调用平台管理员发布接口
- [ ] 若未来阶段不为 `closed`，主体、资金、人工审核、风控、用户救济和联合评审门槛全部有验收证据

## 建议设备矩阵

- 微信小程序：至少覆盖常用 iOS 与 Android 微信版本。
- H5：微信内置浏览器、Safari、Chrome 和常用 Android WebView。
- App：至少覆盖一台较低配置 Android、一台主流 Android 和一台 iPhone。
- 管理后台：Chrome、Edge 和常用桌面分辨率。

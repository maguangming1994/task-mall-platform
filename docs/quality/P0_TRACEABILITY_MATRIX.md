# P0 需求追踪矩阵

本表在需求基线 v1.0 冻结时建立。每个迭代 DoR 前，将对应行拆成具体需求 ID 和 Given/When/Then 场景，并填入负责人、测试用例与执行证据。

| P0 能力 | 主要规则/契约 | 必测范围 | 计划迭代 | 状态 |
|---|---|---|---|---|
| 多端登录与统一身份 | 账号规则、Auth API | 微信/手机号、绑定冲突、会话撤销、权限 | I1 | 部分完成：手机号、微信本地适配、UnionID、人工冲突、用户/后台会话与 RBAC 已通过测试；生产微信凭据待联调 |
| 协议、隐私与注销 | 隐私基线、Privacy API | 同意/撤回、请求、阻断、注销、删除重放 | I1/I7 | 开发完成：协议版本、同意/撤回、补签、隐私请求、私有副本、注销冷静期、匿名化与删除重放已通过测试；正式文本与法务验收待生产准备 |
| 后台 RBAC 与配置 | 权限、配置中心 | 菜单/字段/数据范围、版本、审批、回滚 | I1 | 本地开发完成：登录、权限菜单、配置版本、四眼审批、会话/MFA 和审计已通过测试 |
| 任务发布与版本 | 任务/变更规则、Tasks API | 草稿、审批、预算、重大修改、暂停关闭 | I2/I3 | 本地开发完成：第 11、15 批及全量回归已覆盖 |
| 领取、名额与周期 | 名额规则、Claims API | 并发、周期、取消、过期、补位、自动加入 | I2/I3 | 本地开发完成：原子占位、奖励预留、取消/过期释放与周期限制已覆盖 |
| 提交、审核与风控 | 任务风控、Submissions API | 附件、次数、审核、申诉、冻结、投诉 | I2/I3 | 本地开发完成：提交、复审、申诉、举报与风险冻结已覆盖 |
| 积分、优惠券与欠额 | 积分/券规则 | 批次、过期、扣减、退款、撤销、欠额 | I2 | 本地开发完成：FIFO 批次、欠额、退款重算与不可变流水已覆盖 |
| 钱包、提现与人工调整 | 钱包规则 | 发放、冻结、消费、退款、提现、二审、对账 | I2/I5 | 本地开发完成；真实微信转账与生产财务验收待联调 |
| 商品、SKU与购买方式 | 商品订单规则 | 三种价格、启用组合、限购、快照、上下架 | I4 | 本地开发完成：三种购买方式及各端一致性已覆盖 |
| 库存、购物车与运费 | 库存/运费规则 | 预占、释放、并发、拆单、模板、现金运费 | I4 | 本地开发完成：库存事务、运费模板与拆单已覆盖 |
| 结算、订单与优惠 | Checkout/Orders API | 优惠分摊、能力降级、超时、幂等、金额重算 | I4/I5 | 本地开发完成：预览令牌、原子建单、快照与超时释放已覆盖 |
| 余额/微信支付 | 支付规则、Payments API | 两种现金来源互斥、回调、查询补偿、对账 | I5 | 本地适配与沙箱流程完成；真实商户、回调和账单待凭据联调 |
| 履约与物流 | 履约规则 | 三种交付、分批发货、数量、物流异常 | I6 | 本地开发完成；正式物流查询供应商为可选外部联调项 |
| 退款、退货与换货 | 售后规则、Refunds API | 未发货/已发货、部分/整项/整单、凭证、上限 | I6 | 本地开发完成；微信真实退款到账待渠道验收 |
| 社区、成长与推荐 | 社区/成长规则 | 发布审核、举报、奖励撤销、推荐里程碑 | I7 | 本地开发完成；正式内容安全供应商待联调 |
| 通知、看板与运营 | 通知/运营规则 | 必要/营销、免打扰、重试、SLA、数据口径 | I7 | 本地开发完成；正式微信模板和短信渠道待联调 |
| 非功能与发布 | NFR、发布策略 | 性能、安全、恢复、真机、灰度、回滚、事故 | I8 | 本地门禁、恢复演练、UAT 与部署脚本完成；目标环境压测、真机和生产灰度待授权 |

强制证据包括自动测试报告、真机记录、对账结果、迁移/恢复演练和适用角色签字；只有代码截图不能作为完成证据。

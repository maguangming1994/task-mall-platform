# 微信小程序真机 UAT 与发布验收清单

## 1. 两类环境必须分开

- 本地真机联调：允许开发者工具“不校验合法域名”，仅用于开发成员手机扫码调试。
- 体验版/正式版：必须使用备案 HTTPS API、微信合法域名、真实微信登录与真实支付配置。
- 所有 AppSecret、商户密钥、APIv3 密钥和证书只能放在服务端私密环境，不进入 uni-app、Git 或截图。

## 2. 发布前准备

1. 微信公众平台已添加开发成员、体验成员，并完成类目和隐私保护指引。
2. `request`、`uploadFile`、`downloadFile` 域名均为 HTTPS 且已登记。
3. 服务端 `APP_ENV=production`、关闭调试、PostgreSQL/Redis/队列/监控均通过就绪检查。
4. 微信登录使用真实适配器；支付回调、退款回调、商户证书与平台证书完成联调。
5. 对曾通过聊天、截图或不安全渠道传递过的 AppSecret、商户密钥执行轮换，再进入生产验收。

## 3. 真机主流程验收

| 场景 | 验收动作 | 通过标准 |
|---|---|---|
| 登录与协议 | 微信登录、手机号绑定、勾选协议 | 首次授权清晰；拒绝后不越权；重新同意可恢复 |
| 每日签到 | 首次签到、重复点击、次日连续签到 | 一天仅入账一次；积分来源和到期日可查 |
| 任务 | 筛选、详情、领取、按步骤提交、审核/申诉 | 状态与后台一致，重复请求不重复发奖 |
| 商城 | 三种购买方式、购物车、现金/余额二选一、微信支付 | 金额、积分、运费拆分准确，支付回调幂等 |
| 售后 | 整项/部分/整单、无需物流、凭证上传 | 累计退款不超付；运费责任和下一步清楚 |
| 社区 | 发帖、评论、点赞、组团、举报/申诉 | 审核状态可见；消息可直达对应内容 |
| 资产 | 积分批次、余额、优惠券、提现 | 流水可追溯；手续费和失败解冻准确 |
| 隐私与客服 | 数据副本、注销资格、创建/回复工单 | 阻塞原因、冷静期、客服下一步清楚 |

## 4. 设备覆盖

- iOS 微信当前正式版：小屏与刘海屏各 1 台。
- Android 微信当前正式版：主流厂商至少 2 台，覆盖全面屏和弱网。
- 弱网/断网、后台切回、授权拒绝、支付取消、重复点击、相册/相机拒绝均需测试。

## 5. 命令与发布门禁

```powershell
pnpm.cmd --dir apps/user-app build:mp-weixin
powershell -ExecutionPolicy Bypass -File scripts/check-wechat-readiness.ps1
# 发布流水线使用严格模式；未通过将返回非零退出码
powershell -ExecutionPolicy Bypass -File scripts/check-wechat-readiness.ps1 -Strict
```

开发者工具导入 `apps/user-app/dist/build/mp-weixin`。体验版通过后再提交审核；正式发布前保留数据库备份、上一版本构建和回滚步骤。

# 产品目标、核心路径与指标

## 1. 产品目标

通过“任务大厅与成长行为获取权益—商城消费—社区互动—再次参与”的闭环，让用户持续获得积分、优惠券或余额，并在统一商城中以积分、现金或现金加积分完成消费。

首版是平台自营模式：任务只由后台平台管理员发布，可从管理后台或用户端任务发布中心操作；商城不开放第三方商家入驻。

## 2. 目标用户与核心需要

| 用户类型 | 核心需要 |
|---|---|
| 任务用户 | 在任务大厅找到合适任务，清楚完成要求，及时获得积分、优惠券或余额 |
| 成长用户 | 通过签到、完善资料、社区互动等可持续积累权益 |
| 商城用户 | 使用积分、现金或现金加积分购买商品，并获得稳定的履约和售后体验 |
| 社区用户 | 发帖、评论、参与互动，并在有效行为后获得对应奖励 |
| 推荐用户 | 邀请新人完成第一次有效任务，再推动新人完成第一笔含现金实付订单 |
| 平台人员 | 发布和审核任务，管理内容、商品、资产、订单、售后和风险 |

“新人完成第一次有效任务”是新手引导与推荐漏斗节点，不是推荐人 500 积分的额外发奖条件。500 积分仍在新人第一笔含现金实付订单完成后发放。

## 3. 核心路径

```text
访问或分享落地
  → 游客浏览任务大厅/社区/商城
  → 登录并绑定手机号
  → 领取任务或自动加入成长任务
  → 完成第一次有效任务
  → 持续任务/社区行为并获得权益
  → 访问商城并完成订单
  → 履约、售后与再次参与/推荐
```

## 4. 北极星指标

北极星指标为“每周完成至少一次有效行为的去重用户数”。有效行为包括人工任务审核或申诉通过、自动核验任务达成、通过风控校验的有效社区行为和已完成商城订单。同一用户一周内只计一次；内部账号、测试账号、机器人和作弊行为不计入。

## 5. 首版观察指标

以下是上线后的初始观察目标，不作为首次发布的硬阻断条件，后续可在后台指标配置中调整：

| 指标 | 初始目标 | 口径 |
|---|---:|---|
| 访客到手机号绑定转化率 | ≥ 20% | 首次访问后 7 天内完成绑定的去重访客/去重访客 |
| 任务领取到有效提交率 | ≥ 50% | 领取并提交任务的有效提交用户/领取用户 |
| 任务审核按时率 | ≥ 95% | 任务快照期限内完成的审核/应审核提交 |
| 被推荐新人首次任务完成率 | ≥ 30% | 绑定推荐关系后 7 天内完成有效任务的新人/有效被推荐新人 |
| 获得奖励后商城访问率 | ≥ 30% | 发奖后 7 天内访问商城的用户/成功获奖用户 |
| 注册到首笔现金订单转化率 | ≥ 5% | 注册后 30 天内完成首笔含现金订单的用户/新注册用户 |
| 30 日留存率 | ≥ 15% | 注册后第 30 日仍有有效行为的用户/同期新注册用户 |
| 支付技术成功率 | ≥ 98% | 渠道受理后成功的支付/有效支付请求，排除用户取消和资格拦截 |

所有日、周、月口径使用 `Asia/Shanghai`；跨端通过统一用户 ID 去重。指标必须保存分子、分母、时间窗口和过滤条件，不能只保存最终百分比。

## 6. 发布硬门槛

- 超卖、重复发奖、重复退款和账务差异为 0。
- 核心资产流水与账户汇总对账一致率 100%。
- 登录、任务、发奖、下单、支付、退款和提现主链路没有 P0/P1 缺陷。
- 预发布环境支付技术成功率达到 98%，失败均有可追踪原因。
- 核心 API 压测基线 p95 不超过 500 ms；正式环境可用性目标不低于 99.9%。

业务转化率受流量和运营内容影响，属于观察与优化指标；正确性、安全性和账务一致性属于发布硬门槛。

## 7. 事件与数据边界

客户端只上报页面访问、任务卡片曝光、商城访问和结算开始等交互事件。任务达成、发奖、支付成功、订单完成和推荐达标必须由服务端业务事件产生。

基础事件包括：`page_view`、`phone_bound`、`task_claimed`、`task_submitted`、`task_approved`、`referral_first_task_completed`、`reward_delivered`、`mall_viewed`、`checkout_started`、`payment_succeeded`、`order_completed` 和 `referral_qualified`。

分析事件不得携带手机号、OpenID、访问令牌、详细地址或提交材料原文。使用内部用户 ID、匿名访问 ID、客户端类型、事件时间和经过白名单审核的属性。

## 8. 看板节奏

- 每日：任务名额、提交、审核超时、发奖失败、支付失败、资产差异和售后异常。
- 每周：北极星指标、核心漏斗、推荐新人首次任务完成率和留存。
- 每月：来源质量、奖励成本、商城收入、退款率、用户资产负债和规则调整效果。

目标值变更记录版本、修改人和原因；业务事实的历史统计口径不得随目标值修改而改变。

# 需求基线检查清单

## 已确认

- [x] 首发平台：微信小程序、通用 H5（公众号内及微信外浏览器）
- [x] 商城购买方式：纯积分、纯现金、现金加积分
- [x] 混合支付 MVP：后台配置每个 SKU 固定现金额和固定积分额
- [x] 同一 SKU 可开启一种、两种或全部三种购买方式
- [x] 运费只使用现金支付
- [x] 积分具有有效期，退款积分从入账时重新计算有效期
- [x] 后台统一设置默认积分有效期，各积分来源可覆盖默认值
- [x] 已规划来源：签到、论坛发帖、评论、完善资料、推荐新人
- [x] 推荐新人奖励条件：新人绑定手机号且第一笔含现金实付的订单完成
- [x] MVP 包含基础论坛、评论、审核、举报和违规积分处理
- [x] 支持按数量部分退款、整项退款和整单退款
- [x] 优惠券可以抵扣现金、积分或同时抵扣两者
- [x] 每笔订单最多使用一张优惠券，不能叠加
- [x] 整单取消或整单退款返还优惠券；部分退款不返券
- [x] 优惠券默认领取后 30 天，活动券可配置固定有效期
- [x] 优惠券支持全部、分类、商品和 SKU 适用范围
- [x] 优惠券支持系统、后台和活动三种发放方式
- [x] 返券有效期取原有效期与返券时间加 7 天中的较晚值
- [x] 退货运费按退货原因和责任方确定，不固定由卖家承担
- [x] 发货和退货均支持实体物流、无需物流、虚拟交付
- [x] 未发货退款、无需物流和虚拟商品不填写退货物流
- [x] 实体商品获批退货后 7 天未填写物流自动关闭
- [x] 退款数量及累计现金/积分不能超过剩余可退值
- [x] 退货运费补偿必须有物流单号和付款凭证
- [x] 小程序、微信内 H5、微信外 H5 使用相同价格
- [x] 游客可浏览，领取任务、互动、下单、售后和提现必须登录
- [x] 任务、社区、钱包和下单前必须绑定已验证手机号
- [x] 小程序、公众号和手机号身份合并到统一用户，冲突账号人工处理
- [x] Access Token 默认 2 小时、Refresh Token 默认 30 天、最多 5 台活跃设备
- [x] 注销前检查未结业务和冻结资产，余额必须归零，默认 7 天冷静期
- [x] 注销后个人资料匿名化，交易、账务和审计记录按必要期限保留
- [x] 商品使用 SPU + SKU，SKU 配置价格方案、库存、限购和单一交付类型
- [x] 不同交付类型自动拆成独立订单，每个订单独立优惠、支付、履约和售后
- [x] 待支付订单和库存预占默认 15 分钟，超时释放库存、积分和优惠券
- [x] 库存不得为负，入库、预占、释放、扣减、退货和盘点均生成流水
- [x] 低库存默认阈值 10 件，支持 SKU 覆盖
- [x] 支持单笔、每日、活动期和终身限购
- [x] 实体、无需物流、虚拟交付分别使用 48 小时、24 小时、10 分钟默认履约期限
- [x] 实体、无需物流、虚拟交付分别在发货/交付后 10 天、3 天、1 天自动完成

- [x] 默认参数全部通过后台配置中心修改，不写死在代码中
- [x] 配置支持控件选择、草稿、发布、版本、审计和回滚
- [x] 任务奖励支持积分、优惠券和余额，可组合配置
- [x] 提交次数和审核期限提供全局默认值，并允许任务单独修改

- [x] 任务附件默认图片 9×10 MB、视频 1×100 MB、文件 5×20 MB

- [x] 所有奖励任务设置总奖励次数，周期任务设置单周期上限

# 任务大厅展示、搜索与推荐规则

## 1. 大厅栏目

首版一级栏目为：推荐、限时、日常、成长、全部。首次进入默认展示推荐栏目；同一屏幕内同一任务只出现一次。

| 栏目 | 进入条件 |
|---|---|
| 推荐 | 运营置顶或规则推荐，且任务对当前访问者可见 |
| 限时 | 有明确领取截止时间且仍在领取期 |
| 日常 | 每日、每周或可重复任务 |
| 成长 | 新手成长、资料、签到和其他成长类任务 |
| 全部 | 所有当前可公开展示的任务 |

栏目、排序权重、置顶数量和显示名称通过后台版本化配置。

## 2. 推荐与置顶

- MVP 使用可解释的规则推荐，不采用机器学习或付费竞价排名。
- 默认排序优先级：运营置顶 → 当前用户可参与 → 即将截止 → 最新发布。
- 首页最多置顶 3 个任务，后台可以调整上限和顺序。
- 用户端发布者只能提交推荐位申请，不能直接设置置顶、顺序或推荐有效期。
- 推荐位由有权限的后台运营审批并记录申请人、审批人、理由、位置和有效期。
- 发布者不能审批自己的推荐位申请；置顶到期后自动回到规则排序。

## 3. 搜索与筛选

- 搜索范围：任务标题、标签、业务分类和面向用户展示的发布主体名称。
- 筛选条件：分类、奖励类型、参与方式、周期类型、截止时间和是否可参与。
- 默认每页 20 条，允许后台调整全局默认值，接口最大值仍受服务端限制。
- 搜索结果只包含当前访问者可见的已发布任务；草稿、待审批和私有预览不能进入搜索索引。
- 搜索索引延迟或故障时回退到数据库基础查询，不返回未发布任务。

## 4. 可见性与资格

| 场景 | 展示规则 |
|---|---|
| 游客访问公开任务 | 可以浏览；资格显示“登录后查看” |
| 登录且符合资格 | 显示可领取和实际完成期限 |
| 登录但不符合普通公开条件 | 默认显示任务及明确原因，如“仅限新用户” |
| 定向保密任务且不符合资格 | 完全隐藏，直接访问也返回不可见 |
| 已领取 | 显示进行中、审核中、已完成或已结束状态 |
| 名额已满 | 仍可查看，按钮禁用并显示“名额已满” |
| 暂停 | 大厅禁止新领取；已领取用户从“我的任务”进入 |
| 到期/关闭 | 从大厅默认列表隐藏，历史记录和原公开链接显示结束状态 |

服务端在列表、详情和领取时分别校验可见性与资格。列表返回的资格和剩余名额只是当前快照，领取时必须重新校验。

## 5. 卡片和详情

任务卡片至少展示：

- 平台发布主体名称
- 标题、标签和业务分类
- 奖励摘要
- 参与方式和周期类型
- 当前剩余名额和截止时间
- 当前用户任务状态或资格提示

任务详情展示步骤、资格条件、奖励、预算保障、实际完成期限计算方式、材料要求、审核期限、驳回重提、申诉、取消和名额释放规则。系统自动核验任务明确标注“无需上传材料”。

## 6. 分享与访问

- 只有已发布且当前可公开访问的任务可以生成分享链接。
- 分享链接只携带公开任务 ID、签名推荐码和必要渠道参数，不得包含 Token、手机号、OpenID、后台账号或任务材料。
- 定向保密任务默认禁止公共分享；内部邀请链接仍需登录后重新校验目标资格。
- 预览链接仅对当前发布者和有审核权限的后台账号有效，不能转成公开任务链接。

## 7. 数据统计

按统一用户和匿名访问 ID 记录任务曝光、详情点击、登录、领取尝试、领取成功、提交、完成和发奖漏斗。客户端曝光与点击只用于分析；领取、完成和发奖必须由服务端业务事实产生。

统计事件不携带手机号、OpenID、Token、材料原文或订单内容。内部账号、测试账号、机器人和已识别作弊流量从产品指标中排除。

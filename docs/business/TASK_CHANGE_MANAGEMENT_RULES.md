# 任务发布后修改、暂停、关闭与归档规则

## 1. 修改分类

### 1.1 普通修改

不改变参与资格、用户义务或资产权益的修改，例如错别字、封面替换、说明补充和不影响搜索含义的标签调整。普通修改仍生成新版本并记录差异，可以通过完整校验后直接发布。

### 1.2 重大修改

包括奖励类型或数量、资格、参与方式、核验方式、材料字段、最大成功奖励次数、预算、领取/完成时间和申诉规则变化。重大修改必须创建新版本并重新执行预算、风险和必要审批。

服务端根据实际字段差异判定修改类型，客户端和发布者不能自行把重大修改标记为普通修改。

## 2. 版本和已有用户

- 已发布版本不可原地覆盖，每次修改形成不可变版本及字段差异。
- 新版本审批期间，原已发布版本继续服务新领取；需要立即停止时由发布者或后台主动暂停任务。
- 新版本发布时原子切换当前公开版本，只影响切换后的新领取用户。
- 已领取用户永久使用领取快照，不得降低奖励、缩短期限、增加材料或改变核验方式。
- 回滚实际复制历史版本生成新的待发布版本，不修改历史版本和用户快照。
- 多人编辑必须提交乐观锁版本号，冲突后刷新并重新处理差异。

## 3. 奖励、预算和名额修改

- 减少奖励只影响新版本；已有占位用户保持原奖励和预算预留。
- 增加奖励或奖励次数前必须追加并锁定预算；是否补发既有用户必须走独立补偿流程。
- 增加名额在预算足够并完成必要审批后生效。
- 减少名额不得低于当前占位数加成功奖励数，也不能释放审核、申诉或奖励重试中的预算。
- 任务余额总预算或单人余额奖励超过既有门槛时继续触发财务二审。

## 4. 时间和流程修改

- 延长领取期或活动期允许，但记录原因和版本。
- 缩短领取期只停止新的领取，不能改变已有用户实际完成期限。
- 修改完成期限只影响新领取用户；已有用户保留领取时截止时间。
- 参与方式、核验方式和材料结构只对新版本生效，不能迁移进行中的用户任务。
- 定时任务开始前可以修改；重大变更撤回原排期，重新校验通过后再进入待开始。

## 5. 暂停、恢复和关闭

### 暂停与恢复

- 暂停立即停止新领取、自动加入和释放名额后的补位。
- 已参与用户默认继续提交、审核、申诉和发奖。
- 恢复前重新检查领取时间、预算、风险状态和当前公开版本。

### 关闭

- 没有进行中用户时，拥有权限的发布者可以直接关闭自己的任务。
- 存在进行中用户时，前端关闭转后台审批，并选择：继续履约、终止不补偿、终止并补偿。
- 终止或补偿必须逐条处理用户占位、奖励预算、通知和流水，不能只修改任务总状态。
- 已关闭任务不能恢复；需要重新开展时复制为新任务并重新发布。

### 违规紧急关闭

后台在违法违规、诈骗、重大安全或资产风险场景可以立即停止新领取和奖励投递，冻结待核查组件并通知相关人员。紧急处置不删除证据、用户任务或账务流水，后续必须完成人工结论和补偿/撤销。

## 6. 推荐位与通知

- 重大修改的新版本发布后，现有推荐置顶暂停；由后台运营复核后重新启用。
- 普通文字修正不自动取消推荐位，但仍记录版本。
- 暂停、关闭、终止、补偿或其他影响已参与用户的动作必须发送站内通知；必要资产和安全消息不能关闭。
- 通知使用用户任务快照说明原规则、处理结果和申诉/客服入口。

## 7. 删除与归档

- 已发布任务不得物理删除。
- 已关闭或已到期且全部审核、申诉、奖励、预算和投诉结清后可以归档。
- 归档任务只读，从普通后台列表和任务大厅隐藏，但审计、历史记录、用户任务和对账仍可查询。
- 草稿在未产生发布申请、预算锁定和外部引用时可以作废；作废仍保留必要操作日志。

- [x] 奖励增加先锁定预算，名额减少不得低于占位加成功数
- [x] 缩短时间和修改完成期限只影响新参与用户
- [x] 暂停停止新参与，已有用户默认继续

- [x] 已发布任务不能物理删除，结清后归档

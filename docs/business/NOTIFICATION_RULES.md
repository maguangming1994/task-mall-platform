# 消息通知规则

## 1. 通知场景与渠道

| 场景 | 站内信 | 微信通知 | 短信 |
|---|---|---|---|
| 登录及账号安全 | 是 | 可选 | 是 |
| 任务领取成功 | 是 | 否 | 否 |
| 任务即将到期 | 是 | 是 | 否 |
| 任务审核通过或驳回 | 是 | 是 | 否 |
| 任务因风险暂停、关闭、恢复或补偿 | 是 | 是 | 否 |
| 积分到账 | 是 | 可选 | 否 |
| 积分到期前 7 天、1 天 | 是 | 是 | 否 |
| 余额到账或后台调整 | 是 | 是 | 否 |
| 提现申请、审核、失败和到账 | 是 | 是 | 可配置 |
| 订单待支付 | 是 | 可配置 | 否 |
| 支付成功 | 是 | 是 | 否 |
| 物流发货、无需物流、虚拟交付 | 是 | 是 | 否 |
| 售后审核与退款结果 | 是 | 是 | 可配置 |
| 社区审核、举报和申诉结果 | 是 | 否 | 否 |
| 系统公告 | 是 | 可配置 | 否 |
| 营销活动 | 用户订阅 | 用户订阅 | 用户订阅 |

## 2. 用户偏好

- 交易、安全、余额、积分、提现和售后等必要消息不能完全关闭。
- 用户可以关闭营销消息。
- 用户可以在允许范围内分别选择站内信、微信通知和短信。
- 默认免打扰时间为 22:00～08:00，用户可以修改。
- 支付、退款、提现、安全和高风险资产变动不受免打扰限制。

## 3. 发送与重试

- 每个业务事件生成唯一通知键，防止重复发送。
- 通知先写入站内消息，再由队列投递外部渠道。
- 外部渠道发送失败默认重试 3 次，采用递增间隔。
- 明确不可重试的错误直接进入失败状态。
- 达到重试上限后进入人工检查或告警队列。
- 外部渠道失败不回滚已经成功的订单、支付、积分或提现业务。

## 4. 模板和变量

- 模板按场景、渠道和语言维护。
- 模板变量使用白名单，禁止在后台输入可执行表达式。
- 发布模板前提供预览和测试发送。
- 资产、安全类消息不得包含完整手机号、地址、Token 或密钥。
- 模板修改支持草稿、版本、审核、发布和回滚。

## 5. 后台配置

- 各场景启用的渠道
- 默认免打扰开始和结束时间
- 提醒提前量，例如任务截止和积分到期
- 用户任务完成期限默认提前24小时和2小时提醒；期限不足时跳过已失去意义的提前量
- 重试次数和间隔
- 通知模板及版本
- 营销订阅和退订规则
- 失败告警阈值

配置变更只影响新生成的通知任务，已经进入队列的通知使用创建时的模板和渠道快照。

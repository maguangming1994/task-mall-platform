# 账号、身份与注销规则

## 1. 游客与登录边界

- 游客可以浏览公开任务、社区内容和商品。
- 领取任务、提交任务、发帖、评论、下单、申请售后和提现必须登录。
- 首发登录方式包括微信小程序登录、微信内 H5 微信授权登录，以及通用 H5 手机验证码登录。
- 用户执行任务、社区互动、钱包操作和下单前必须绑定并验证手机号。
- 用户端任务发布中心只对完成独立后台身份验证的平台管理员开放；普通用户登录态不能发布任务。

游客可浏览范围、强制登录动作和强制绑定手机号动作均由后台配置；支付、提现和账号安全等高风险动作不得通过普通配置取消身份校验。

## 2. 统一用户身份

- 手机号、微信小程序 OpenID、公众号 OpenID 和可获得的 UnionID 统一关联到一个用户账号。
- 身份合并优先使用已验证手机号和 UnionID；OpenID 只在对应微信应用内唯一，不能跨应用直接视为同一用户。
- 合并前必须验证待合并身份，发现两个账号均存在资产、订单或处罚记录时进入人工处理，禁止静默覆盖。
- 身份合并只改变登录入口归属，不合并或重写账务、订单、积分流水与审计记录。

## 3. 用户资料与手机号

- 完善资料奖励的默认完成条件为昵称、头像和已验证手机号均存在，每个用户只奖励一次。
- 更换手机号必须验证当前登录态、新手机号验证码；具备旧手机号验证条件时同时验证旧手机号。
- 旧手机号不可用时进入增强身份核验或人工申诉流程，并记录风险审计。
- 手机号标准化后唯一；变更成功后撤销其他设备的高风险授权，必要时使旧会话失效。

## 4. 会话与设备

- Access Token 默认有效 2 小时，Refresh Token 默认有效 30 天并在刷新时轮换。
- 同一用户默认最多保留 5 台活跃设备，超过上限时按最早未活跃设备退出，用户可在安全中心主动移除设备。
- 退出登录、修改关键身份、账号禁用、注销生效和后台安全处置后，对应会话立即失效。
- 设备记录用于账号安全、消息推送和反作弊，不作为唯一身份凭证。

Token 时长、设备上限和超限处理方式由后台配置；安全处置可直接撤销全部会话。

平台管理员在用户端发布任务时使用独立 `publisher` 会话。该会话与普通用户 Access Token 使用不同受众和权限范围，角色撤销、后台账号禁用、主动退出或超过发布会话期限时立即失效；发布动作前还需满足近期身份验证要求。

## 5. 提现身份

- 提现前必须绑定并验证手机号。
- 微信提现必须存在当前有效、经用户确认的微信收款身份。
- 更换关键身份后可触发可配置的提现保护期；高风险命中时转人工审核。

## 6. 账号注销

用户提交注销前必须通过资格检查：

- 没有进行中的订单、售后、退款、提现或争议。
- 没有冻结的余额、积分或其他待结算资产。
- 钱包可用余额为 0；用户须先消费或提现，不允许后台静默清除。
- 用户明确确认剩余积分和优惠券在注销生效后失效且不补偿。

注销申请通过校验后进入默认 7 天冷静期。冷静期内登录账号或主动撤销申请可终止注销；冷静期结束后再次校验资格，通过后注销生效并撤销全部会话。

注销生效后：

- 昵称、头像、手机号等可匿名化资料按规则脱敏或删除。
- 订单、支付、退款、钱包、积分、发票、风控和审计记录按适用的交易、会计、合规及争议处理期限保留，并与前台身份隔离。
- 已注销账号不得直接恢复；再次注册按新账号处理，历史资产不自动迁移。

详细数据期限、用户数据权利、儿童/敏感信息、第三方共享和删除任务要求见 [`../security/PRIVACY_DATA_RETENTION.md`](../security/PRIVACY_DATA_RETENTION.md)。普通账号资料在注销生效后30天内完成删除或不可逆匿名化；交易、账务、风险和审计数据按其专项期限隔离保存。

冷静期、注销拦截项、剩余积分/优惠券处理和再次注册策略可在后台配置，但不得绕过未结业务、冻结资产和必要数据留存要求。

## 7. 后台禁用与审计

- 后台禁用账号后全部现有会话立即失效，并阻止新登录。
- 禁用、解禁、身份合并、手机号申诉、注销撤销和注销执行均记录操作人、原因、请求 ID、时间、前后状态及必要凭证。
- 管理员不能直接修改 OpenID、UnionID 或把资产覆盖到另一个用户；此类问题必须走受控身份合并或数据修正流程。

## 8. 首版后台默认参数

| 参数 | 初始值 |
|---|---:|
| Access Token 有效期 | 2 小时 |
| Refresh Token 有效期 | 30 天 |
| 活跃设备上限 | 5 台 |
| 注销冷静期 | 7 天 |
| 完善资料必填项 | 昵称、头像、已验证手机号 |

以上均在配置中心展示、校验、发布、审计和版本化；已签发会话是否立即受新时长影响由发布页面明确提示，默认只影响新签发会话。

# 发布与回滚清单

第三十一组已确认的灰度顺序、兼容迁移、监控对账、止损和事故机制见 [`RELEASE_AND_OPERATIONS_STRATEGY.md`](RELEASE_AND_OPERATIONS_STRATEGY.md)。

## 发布前

- [ ] 版本范围和变更说明已确认
- [ ] CI、自动化测试、安全扫描和设计走查通过
- [ ] 数据库迁移在预发布环境演练
- [ ] 生产数据库完成可恢复备份
- [ ] 环境变量、证书、支付回调和域名配置已核对
- [ ] 监控、告警、客服和故障联系人已就绪
- [ ] 小程序/App 隐私、权限、截图和审核材料已准备
- [ ] 功能开关、灰度方案和回滚步骤已确认

## 发布中

- [ ] 记录发布时间、版本、提交号和执行人
- [ ] 先部署兼容性数据库变更，再部署应用
- [ ] 小范围灰度并观察错误、延迟、队列和交易
- [ ] 执行登录、任务、积分、下单和支付冒烟测试

## 发布后

- [ ] 检查支付回调、队列积压、慢查询和异常日志
- [ ] 核对积分、库存、订单、支付和退款账务
- [ ] 逐步扩大流量
- [ ] 更新变更记录并完成发布复盘

## 回滚触发条件

- 核心流程不可用
- 出现重复扣款、重复积分、错误退款或库存账实不符
- 错误率、延迟或队列积压持续超过告警阈值
- 数据迁移导致不可接受的数据错误

涉及数据库回滚时优先使用向前修复；不得在没有备份验证的情况下执行破坏性回滚。

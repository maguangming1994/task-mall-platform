## 如何查看

1. 先按文件名前的序号顺序查看同一角色的完整流程。
2. 对比 PC 管理端各角色的 `02-工作台与可见权限菜单.png`，快速确认菜单隔离。
3. 再打开各业务页面截图，检查按钮、敏感数据、审批入口是否与岗位职责一致。
4. 将需要调整的内容记录为“角色 / 页面 / 当前表现 / 期望表现”，后续可直接转成开发任务。

## 流程口径

- 普通用户：允许手机号注册/登录，并在首次登录后确认当前协议。
- 后台角色：不提供公开注册，账号应由超级管理员或初始化程序创建；因此截图从“角色账号首次登录”开始。
- 平台发布管理员：在移动端使用与普通用户完全隔离的发布会话，通过后台管理员身份验证后才能创建和发布平台任务。
- 截图中的任务领取、加购、草稿保存和发布均发生在本地演示数据中。

## 下一轮建议重点

- 为退款、提现、任务审核、社区审核、发货等页面补充完整演示数据，再截取“同意 / 拒绝 / 二次复核 / 失败”等动作状态。
- 确认仓储人员是否可以看到用户完整地址与电话，以及导出权限是否需要二次验证。
- 确认客服、任务审核员、财务人员之间的售后权限是否需要进一步拆分。
- 确认平台管理员是否只能管理自己发布的任务，运营管理员是否允许代运营或批量操作。
- 在接入真实微信登录、支付、退款和短信服务后，再做一轮真机截图与隐私脱敏检查。

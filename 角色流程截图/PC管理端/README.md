# PC 管理端截图说明

每个角色目录的第 1 张图为角色账号首次登录，第 2 张图为登录后的工作台与完整可见菜单，后续截图按菜单顺序保存。

后台不提供公开注册入口，这是刻意的安全边界。账号创建流程应为“超级管理员创建或系统初始化 → 分配单一角色 → 首次登录 → 后续按安全策略修改密码/启用 MFA”。

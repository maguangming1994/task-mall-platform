# 移动端截图说明

## 01-游客（11 张）

覆盖首页、公开任务大厅、任务二级详情、商城、社区、手机号登录入口、注册前协议，以及新版首页公告弹窗、轮播图、公告栏、任务大厅统计卡片和五入口底部导航栏。

## 02-普通注册用户（24 张）

覆盖手机号注册登录、验证码、首次协议确认、登录首页、个人资料、资产、商城、购物车、订单、售后、消息、推荐新人、任务领取、订单式任务管理、按步骤上传截图与填写文字、提交审核、社区发帖与评论等主流程。

## 03-平台发布管理员（10 张）

覆盖独立登录、填写管理员凭据、发布中心、原任务草稿流程，以及新版悬赏发布的基础信息与业务场景、时限频率、奖励预算安全规则、步骤化验收材料和发布前确认。此身份与普通用户登录态隔离。

截图以 H5 移动视口生成；微信小程序发布前仍需在微信开发者工具和真机上复核导航栏、安全区、授权弹窗与支付组件。

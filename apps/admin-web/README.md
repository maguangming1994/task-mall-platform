# 管理后台

基于 React、TypeScript 和 Ant Design，提供任务审核、用户、积分、商品、库存、订单、支付和运营管理能力。

## 目录职责

- `src/api`：后台 API 客户端
- `src/components`：通用组件
- `src/features`：按业务领域组织的页面及逻辑
- `src/features/growth`：积分来源、有效期、签到和推荐规则
- `src/features/wallet`：余额奖励、钱包流水和人工调整
- `src/features/community`：帖子、评论和内容审核
- `src/features/settings`：业务参数、功能选择、配置版本和发布审核
- `src/layouts`：后台布局
- `src/routes`：路由和权限守卫
- `src/stores`：全局状态
- `src/styles`：全局样式和主题
- `src/types`：后台类型
- `src/utils`：通用工具

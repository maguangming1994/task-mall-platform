# 前端任务发布中心

此分包用于平台管理员在用户端创建和发布任务，首版不向普通用户开放。

## 页面

- `index`：我发布的任务及状态筛选
- `edit`：分步骤创建和编辑草稿
- `preview`：按用户端实际任务卡片和详情预览
- `publish-result`：发布校验、待审批、驳回、排期或发布结果

## 安全边界

- 进入分包前调用发布者身份接口，不以本地角色字段决定权限。
- 普通用户 Access Token 不得调用发布接口；使用独立、短时、限权的发布会话。
- 平台管理员角色或权限撤销后，立即清除发布会话并返回普通任务大厅。
- 草稿只显示当前发布主体的数据；发布主体 ID 由服务端会话确定，客户端不能提交。
- 发布、重大修改、暂停和关闭均二次确认，发布前按服务端结果决定是否进入后台审批。

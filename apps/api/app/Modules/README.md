# 领域模块

每个模块内部可按需要建立：`Controllers`、`Requests`、`Services`、`Models`、`Repositories`、`Events`、`Listeners`、`Jobs` 和 `Enums`。

- `Auth`：登录、Token 与第三方身份绑定
- `User`：用户、地址与设备
- `Task`：任务、领取、提交与审核
- `Points`：积分账户与流水
- `Wallet`：用户余额、余额奖励和钱包流水
- `Growth`：签到、完善资料、推荐新人和积分事件
- `Community`：论坛帖子、评论和内容审核
- `Product`：分类、SPU 与 SKU
- `Inventory`：库存与库存流水
- `Cart`：购物车
- `Order`：订单、履约与售后
- `Payment`：支付、回调与退款
- `Notification`：站内信、短信与推送
- `Admin`：后台权限与管理接口
- `Audit`：审计日志
- `Settings`：后台参数配置、版本、发布和缓存刷新

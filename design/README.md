# 产品与 UI 设计

集中管理用户端和管理后台的产品原型、视觉设计及开发交付资源。

完整设计流程和验收标准见 [`DESIGN_PLAN.md`](DESIGN_PLAN.md)。

## 目录职责

- `prototypes`：产品流程图、线框图及可交互原型说明
- `ui/user-app`：uni-app 用户端 UI 设计稿
- `ui/admin-web`：管理后台 UI 设计稿
- `design-system`：颜色、字体、间距、图标和组件规范
- `assets/icons`：图标源文件
- `assets/images`：图片和插画源文件
- `exports/user-app`：交付给用户端开发的切图和标注
- `exports/admin-web`：交付给管理后台开发的资源
- `references`：竞品截图和设计参考，仅用于内部分析

## 文件命名建议

- 页面：`模块-页面-状态`，例如 `任务-任务详情-已领取.png`
- 组件：`组件-变体`，例如 `按钮-主要操作.svg`
- 原型版本：`prototype-v1.0`、`prototype-v1.1`
- 导出图片优先使用 SVG、WebP 或 PNG，避免重复保存无意义副本

## 管理原则

- 原始设计文件与开发导出文件分开存放。
- 用户端和管理后台资源分开存放。
- 大型设计源文件后续建议使用 Git LFS，或在此保存云端设计链接及版本说明。
- 涉及商业授权的字体、图片和图标，需要在对应目录记录授权来源。

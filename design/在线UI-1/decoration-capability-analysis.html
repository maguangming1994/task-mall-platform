一、参考后台的通用面板骨架

三段式
三栏结构：左侧组件库（基础 / 店铺 / 营销 / 功能 / 会员分组），中间手机画布（选中蓝框 + 悬浮工具：上移、下移、复制、设置），右侧属性面板。属性面板固定三段：
段落配置项作用
组件布局外边距（四向，可负值）、内边距（四向）、组件圆角（四角独立）、组件背景（无 / 纯色 / 图片）、显示渠道（多端多选）、显示时间（0–24 点区间）、订阅消息绑定所有组件通用，决定占位与可见性。
组件样式图标形状 / 高度、行间距、字号 / 粗细 / 斜体、每行数量、显示类型（普通 / 多页滑动）、圆角幅度、滚动速度、颜色组（内层 / 图标 / 文字）、比例、指示器、透明度、位置按组件类型提供展示细节。
内容手动填写，或调用平台数据（幻灯片 / 公告 / 商品分类 / 同城信息）；读取数量 5 / 10 / 20；条目级图标、文字、颜色、链接、角标四形态数据来源与条目维护。

兼容策略：
  • 新增字段全部可选；旧配置缺失字段时按默认值渲染，线上视觉不变。
  • 后端校验只做边界约束与白名单，不要求一次提交全部字段；草稿保存失败不会影响线上。
  • 后台预览、用户端渲染与后端校验三处字段名保持一致，避免“后台能配、端上不生效”。

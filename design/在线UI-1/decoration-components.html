通用规范

先读这里
装修页面与槽位：首页（积分卡之后）、社区首页（工具条之后）、商城首页（搜索区之后）、我的页面（用户信息卡之后）。装修只做增量插入，原生积分卡、TabBar、弹窗等不受影响；某页没有可见区块时不渲染任何内容，页面与原来完全一致。
页面级设置（每个页面独立）：
字段限制 / 默认说明
name 页面名称≤30 字，可空仅后台识别使用，不展示给用户。
title 页面标题≤40 字，可空非空时展示在装修区域顶部。
description 页面介绍≤200 字，可空后台说明/活动备注，不在用户端展示。
cover_url 页面封面URL，可空后台页面识别用，可留空。
background_color 背景色#RRGGBB，可空装修区域底色，留空使用页面默认。
background_url 背景图URL，可空设置后铺满装修区域，优先于背景色。
每个组件的通用样式（组件设置 → 组件样式）：
样式项取值 / 默认说明
外边距 margin上右下左各 0–100，默认 0组件外侧留白，用户端按 rpx 渲染。
内边距 padding上右下左各 0–100，默认 0组件内侧留白，背景色会覆盖内边距区域。
圆角 radius0–100，默认 0作用于组件外层容器。
四角独立圆角 corner_radius开 / 关，默认关；每角 0–100开启后按左上/右上/左下/右下分别渲染，覆盖统一圆角。
整体透明度 opacity20–100，默认 100降低组件整体不透明度，适合做背景装饰或弱化提示。
每日显示时段 display_daily_*HH:mm，可空每天固定时段展示；结束时间小于开始时间视为跨零点，留空表示全天。
背景无 / 纯色 / 图片 / 渐变，默认无纯色填 #RRGGBB；图片支持上传或 URL；渐变填 CSS，如 linear-gradient(135deg,#12D978,#08A152)。
边框开 / 关，默认关开启后可设边框颜色，未填默认 #E7EBF2。
阴影开 / 关，默认关为组件增加卡片阴影。
显示渠道H5 / 小程序，默认全选只勾选的渠道会渲染该组件；全部取消时按全选处理。
显示时段YYYY-MM-DDTHH:mm，可空开始/结束均留空表示长期展示；到点自动显示或隐藏。

校验与限制（保存草稿时生效）：
  • 每个页面最多 30 个区块；区块标识仅允许字母、数字、下划线与短横线，同页不可重复。
  • 图片与链接仅允许 https://、http:// 或以 / 开头的站内路径。
  • 颜色统一为 #RRGGBB；富文本会经后端清洗，脚本与事件属性会被移除。
  • 不合规配置在保存草稿阶段直接拦截，不会影响线上。

发布与回滚

上线流程
1. 保存草稿：填写修改说明（≥4 字）后保存。草稿只写草稿表并递增锁版本，线上接口与用户端完全不受影响。若提示“草稿已被其他管理员更新”，刷新页面后基于最新草稿继续编辑。
2. 发布：点击发布并二次确认，完成近期核验后生成新版本，刷新配置缓存；用户端下一次拉取 `/api/v1/page-decoration` 即生效。
3. 版本与回滚：版本历史记录来源、原因与时间。回滚会基于目标历史版本生成“回滚草稿”，仍需再发布一次才会生效，并生成新的版本号；历史版本不会被删除。
4. 上线前自检：
  • 手机画布中确认区块顺序、启停状态与图片是否正常。
  • 检查显示渠道与显示时段是否符合活动安排。
  • 发布后在 H5 与小程序分别确认一次；异常时用版本历史回滚。

# 用户端原型 V1

## 页面地图

```text
首页
├─ 今日推荐 → 任务大厅 → 领取 → 提交 → 审核/申诉 → 奖励
├─ 精选兑换 → 商品列表 → 购物车 → 结算 → 支付 → 订单
├─ 成长社区 → 帖子/评论 → 举报/申诉
└─ 账户状态 → 登录/协议 → 我的 → 资产/地址/订单/消息/推荐

底部导航：首页｜任务｜商城｜社区｜我的
```

## 首页高保真结构

1. 品牌头部与账户入口。
2. 核心价值主视觉：做任务、得奖励、换好物。
3. 四个高频入口：任务、商城、社区、订单。
4. 今日推荐任务，突出奖励和预计耗时。
5. 精选兑换双卡片，表达三种购买方式。
6. 资产可信说明，进入积分与余额流水。
7. 游客登录行动；登录后改为个性化资产摘要。

## 关键页面状态

每个列表页统一覆盖加载、正常、空数据、网络错误与重试。任务和订单额外覆盖已结束、名额用尽、处理中、部分成功、超时与申诉中。资产页必须区分可用、冻结、欠额和临近过期。

## 第一轮验收重点

- 375×812、390×844、430×932 三种移动视口无横向溢出。
- 微信小程序和 H5 底部导航一致。
- 游客能浏览任务、商品和社区，但领取、下单、互动时进入登录。
- 现金、积分、现金+积分三种价格在列表与结算使用一致文案。
- 管理员前端发布入口只对已验证的平台管理员开放，不作为普通用户主导航。

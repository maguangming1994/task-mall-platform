使用说明

1. 图标文件存放于 apps/user-app/src/static/icons/ 目录
2. TabBar 图标需提供普通态和选中态两份资源
3. 组件中使用方式：<image src="/static/icons/tasks.svg" />
4. 如需调整颜色，使用 CSS color 属性控制 currentColor

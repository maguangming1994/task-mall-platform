# 任务商城视觉系统 V1

## 产品气质

首发版本采用“可信、清爽、轻活力”的中性品牌方案。深蓝负责建立平台和资产安全感，明蓝负责主要行动，暖橙只用于积分与奖励，避免把任务和商城做成高噪声促销页面。

## 核心 Token

| Token | 色值 | 用途 |
|---|---:|---|
| `brand-900` | `#10295F` | 深色品牌背景、重要标题 |
| `brand-700` | `#2455C3` | 强调文字、选中态 |
| `brand-600` | `#2F67DF` | 主按钮、主行动 |
| `brand-100` | `#EAF1FF` | 品牌浅底、选中背景 |
| `reward-600` | `#E56A16` | 积分、奖励和收益数字 |
| `reward-100` | `#FFF0DF` | 奖励浅底 |
| `ink-900` | `#172033` | 主文字 |
| `ink-500` | `#748099` | 辅助文字 |
| `line` | `#E7EBF2` | 分隔线和描边 |
| `canvas` | `#F6F8FC` | 页面底色 |
| `success` | `#15966A` | 成功状态 |
| `danger` | `#D14343` | 风险与破坏性操作 |

间距使用 4px 基础栅格；用户端卡片主圆角 14–18px，按钮点击高度不低于 44px。正文、标签和状态不只依赖颜色表达。

## 用户端组件

- 品牌头部：品牌标记、页面身份、消息与头像入口。
- 任务卡：类型、标题、奖励、剩余名额、完成时限与单一主行动。
- 商品卡：商品视觉、购买方式、现金/积分价格和交付类型。
- 资产卡：可用、冻结、有效期与流水入口分层显示。
- 空状态：说明当前状态、给出下一项可执行操作，不使用无授权插画。
- 字标图标：小程序首版采用统一圆角字标，避免跨端 SVG 兼容差异；后台继续使用统一线性 Ant Design 图标。

## 管理后台

桌面端沿用同一品牌色，但提高信息密度。侧栏负责业务域，页头负责环境、待办和账号，内容区以指标、待处理事项和风险提示组织，不再展示开发批次文案。

## 多端规则

- 微信小程序、微信内 H5 和外部浏览器 H5 共用布局、Token 和业务组件。
- H5 宽屏下保持 375px 设计宽度的居中内容，不把移动页面拉伸成桌面网页。
- 底部五栏为：首页、任务、商城、社区、我的。
- 安全区、软键盘、系统返回和原生授权弹窗必须在真机 UAT 单独验收。

## 资源授权

V1 不引入外部图片、字体或插画；品牌标记、CSS 图形和字标图标均为项目内原创代码资源。后续增加摄影、插画或图标包时，必须记录来源、许可证、允许平台和替换方案。

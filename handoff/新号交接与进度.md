## 1. 项目是什么

**校园任务商城**：面向高校学生的一体化小程序平台，一个微信小程序内包含五条业务线：

| 业务线 | 内容 |
|---|---|
| 任务大厅 | 发布/领取校园任务（取快递、代排队、活动协助等），积分悬赏 |
| 积分商城 | 积分 + 现金混合支付兑换实物/虚拟商品 |
| 校园社区 | 图文帖子、话题分类、点赞评论、组团活动 |
| 闲置交易 | 二手商品发布→平台审核→托管支付→发货/面交→收货→评价→退款仲裁 |
| 成长与资产 | 每日签到、积分、优惠券、校园钱包（充值/提现/流水） |

三种用户角色：**学生用户**（小程序）、**平台管理员**（admin-web 后台）、**超级管理员**（全部权限 + 审计）。

## 2. 代码结构与技术栈

```
task-mall-platform/
├── apps/
│   ├── api/          # Laravel 后端（PHP 8+），业务按模块组织在 app/Modules/
│   ├── user-app/     # uni-app + Vue3 + TS + Vite + Pinia 小程序（主开发对象）
│   └── admin-web/    # React + Vite + TS 管理后台
├── infra/
│   ├── compose.yaml              # 本地基础设施（postgres/redis/minio）
│   ├── compose.production.yaml   # 生产全栈（api/queue/scheduler/reverb/nginx/pg/redis）
│   ├── nginx/、docker/、php/     # 镜像与反代配置
│   └── .env.production.example
├── design/           # UI 设计稿（见第 7 节）
├── docs/             # 全套业务/架构/运维文档（见第 8 节索引）
└── handoff/          # ← 本交接资料所在目录
```

**关键技术点**
- 后端：Laravel，模块化目录 `app/Modules/*`；API 前缀 `/api/v1`；统一响应 envelope（ApiResponse）
- 实时通信：Laravel Reverb（WebSocket），IM 消息事件 `ChatMessageSent`；私有频道 `chat.conversation.{publicId}`，授权在 `routes/channels.php`
- 小程序：**pages.json 中没有配置原生 tabBar**，全局底部导航是自定义组件 [AppTabBar.vue](file:///c:/Users/Administrator/Desktop/trae/task-mall-platform/apps/user-app/src/components/AppTabBar.vue)，中间「商城」项为绿色渐变圆形凸起按钮
- 小程序底部导航图标优先级：导航装修远程图 > 后台图标配置（IconConfig）> 包内静态图
- 文件存储：本地 Minio（S3 协议），生产为 S3/本地卷
- 状态管理：Pinia stores（auth / modules / campus / navigation / icons）

## 4. 本地环境启动（从零开始）

**前提**：Docker Desktop、Node 24（user-app 要求 `>=24 <25`，见 .nvmrc）、PHP 8+ 与 Composer。

### 4.1 基础设施

```powershell
docker compose -f infra/compose.yaml up -d
# postgres:5432 / redis:6379 / minio:9000(控制台9001)
```

### 4.2 后端 API（apps/api）

```powershell
cd apps/api
composer install
copy .env.example .env          # PowerShell；默认 DB/Redis/Minio 配置与 compose 一致
php artisan key:generate
php artisan migrate
php artisan db:seed              # 基础数据（校区/RBAC/设置/图标/法律文档等）
php artisan db:seed --class=DemoDataSeeder   # 可选：演示任务/商品/帖子 + 测试账号
php artisan serve                # http://127.0.0.1:8000
```

### 4.3 小程序（apps/user-app）

```powershell
cd apps/user-app
npm install
npm run dev:mp-weixin            # 产物在 dist/dev/mp-weixin
```

用**微信开发者工具**导入 `apps/user-app/dist/dev/mp-weixin` 目录。
注意：仓库内 `src/manifest.json` 的 `appid` 为空，需在开发者工具中填入真实小程序 AppID（或使用测试号）。

### 4.4 管理后台（apps/admin-web）

```powershell
cd apps/admin-web
npm install
npm run dev                      # vite 默认 http://localhost:5173
```
